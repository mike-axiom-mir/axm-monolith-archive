# AXM Monolith Archive — Agent Guidance

This repository is an archive/index, not a builder, foundation, platform, or CANON authority.

## First action for any AI

Read `CURRENT.json` before doing anything else. Treat it as the explicit selected pointer to the best known archived test body.

## Promotion rule

Do not change `CURRENT.json` merely because a newer monolith exists. Promotion requires an explicit deliberate choice that the newer body is the better archive target.

Before promoting:
- exact ZIP bytes must exist;
- SHA-256 must be known;
- archive/release transport must be real, not promised;
- provenance and evidence state must remain explicit;
- previous CURRENT may be moved into `archive/index.json` only if deliberately selected for historical preservation.

## Truth boundaries

- Archive presence != CANON.
- Newer != better.
- Candidate != verified.
- Declared != executable.
- Test evidence != native execution.
- ZIP integrity != semantic correctness.
- Git/GitHub permission != constitutional authority.

The four AXM roots remain the merge gate: Truth, Agency/non-domination, Continuity, Wisdom before speed.

## Artifact rule

Full monolith ZIPs belong in GitHub Releases, not ordinary Git blobs. Metadata in this repository must never claim a release asset exists before it actually exists and its SHA-256 matches the selected body.

## Historical bodies

Only deliberately chosen older bodies belong under `archive/index.json`. Do not dump every intermediate checkpoint into history.
