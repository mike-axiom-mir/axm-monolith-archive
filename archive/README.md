# Historical Monolith Bodies

This folder indexes only deliberately selected older monolith bodies.

Do **not** add every intermediate checkpoint. When a newer body becomes CURRENT, preserve the previous CURRENT here only when it is historically or practically worth keeping.

Each selected historical entry should record:

- exact version and filename;
- SHA-256 and byte size;
- GitHub Release tag / asset name;
- parent lineage when known;
- concise evidence state;
- why this body was deliberately kept.

Historical ZIP bytes should remain immutable as GitHub Release assets.
